WeTalk V1 Prototype

Open index.html to view the prototype.

Included:
- WeTalk homepage
- Login/onboarding prototype
- Community dashboard
- Channels and messaging demonstration
- WEAI assistant interface
- Responsive desktop and mobile design
- Copyright 2026 and FEEZ Tech Limited credit

Important:
This is a visual prototype. Information is stored only in the browser. Live WEAI/OpenAI answers, image generation, real accounts, and real-time communication require the separate server version. No OpenAI API key is included in this folder.

Sharing:
You can publish this folder as a static website to let others view and try the demo. Each visitor gets separate browser-local demo data; publishing it does not connect the real server features. Keep the assets folder alongside index.html.
