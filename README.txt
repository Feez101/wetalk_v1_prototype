WeTalk V1 Prototype

Open index.html to view the prototype.

Included:
- WeTalk homepage
- Browser-only onboarding demo (not real sign-in)
- Community dashboard
- Simulated channels, messages and file-name preview
- WEAI interface preview (live answers disabled on the hosted demo)
- Responsive desktop and mobile design
- Copyright 2026 and FEEZ Tech Limited credit

Important:
This is a static prototype, not a live service. Demo profiles, communities and messages are stored in this browser only. The hosted demo does not send WEAI prompts or context to a server. Real accounts, shared messaging, file uploads, roles, and live AI require a separately implemented and reviewed backend. No OpenAI API key is included in this folder.

Sharing:
Each visitor gets separate browser-local demo data; publishing does not connect production services. Keep the assets folder alongside index.html.

Feedback:
Use the “Give feedback” link on the site to open the public GitHub feedback form. Do not submit passwords, private messages, personal contact details, or other sensitive information.
