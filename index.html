Privacy & control

Your community should stay in control.

WeTalk V1 is being structured around protected accounts, server-side secrets, validation and role-based permissions. Security claims will only be made when the underlying feature is actually implemented and tested.

🔐 Server-side authenticationPasswords belong in the backend and are never stored as plain text in the production application.
🛡 Roles & permissionsCommunity owners and admins can control who manages channels and members.
🔑 Protected API keysOpenAI credentials stay on the Laravel server, not inside browser JavaScript.
✅ Launch auditUploads, permissions, deployment settings and HTTPS should be checked before public release.
📶 Future expansion

Local-network communication

The original WeTalk vision includes communication over shared Wi‑Fi or a local network. That remains a differentiating idea, but it should be treated as a later implementation milestone until the production networking behavior is fully built and tested.

Questions

What people will want to know.

Does WeTalk require a phone number?

The V1 concept is designed around email + username identity, so a phone number is not required for the prototype flow.

Is WeTalk only for schools?

No. The product is being designed for schools, businesses, organizations, gaming groups, communities and other teams that need organized communication.

Does WeTalk already support voice and video?

Not in the V1 launch scope. Those are later features so the first release can focus on a reliable community messaging experience.

Is the AI assistant private?

The Laravel design keeps the OpenAI API key on the server. In the planned V1 flow, content is sent to AI only when the user deliberately asks the assistant to process it.

Can I try the product without setting up Laravel?

Yes. The standalone prototype includes an interactive homepage, registration flow and dashboard using browser-local demo state.

Welcome to WeTalk 👋

WEAI will show you the important parts before you enter your first community.

1. Communities are your main spaces.
Create one for a school, team, organization, gaming group or any community — or join one with an invite code.

Use channels such as #general, #announcements or topic channels so messages stay easy to find.
